# 密室現場中控（離線版）

這是手機優先的離線網頁 App。工作、採購、備品／領用和發票紀錄會先留在目前裝置的瀏覽器中；照片會縮小後一併保存。

## 使用方式

1. 先以網路開啟 `index.html`（建議用本機網頁伺服器或網站主機開啟，才能安裝為手機 App）。
2. 在手機瀏覽器選擇「加入主畫面」或「安裝 App」。
3. 首次載入後，即使沒有網路也可開啟與新增紀錄。
4. 定期按「匯出備份」，把 JSON 備份放到安全的位置；換手機時，用「匯入備份」還原。

## 限制

- 資料完全留在單一手機，離線時不會自動同步給其他人。
- 多人同步、雲端備份與回寫 Notion，必須在有網路時另加同步服務。

## Apps Script 同步

App 已預先設定案件進度系統網址。要完成同步，請把 `google-apps-script-sync.gs` 的處理函式整合到現有 Apps Script 的 `doPost(e)` 路由中；部署新版 Web App 後，手機 App 的「同步」才會收到確認。同步接收端會用紀錄 ID 去重複，因此同一筆資料重送不會重複建立。照片會放進 Google Drive 的「密室現場照片」資料夾，試算表只保存照片連結。
